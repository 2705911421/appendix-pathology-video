# 大体阑尾 r6 自检

基线：gross-dev，r5 提交 197b6e9（开工时 HEAD 7c34018）。只改化脓态、坏疽态的脓苔。正常态、单纯性态、细长形状、四态排列、系膜、标签沿用 r5。

像素核对（对照 HEAD 的 r5 静帧，数字在 verification_r6.json，未上屏）：

- gross_正常.png、t_000.00.png 与 r5 逐像素一致（0 / 2073600）。
- gross_红.png、t_001.00.png 与 r5 逐像素一致（0 / 2073600）。这两张未纳入本轮提交，避免同像素重编码。
- gross_四态.png 左上、右上两格（正常、单纯性）与 r5 四态图逐像素一致；左下化脓格改 87228 像素，右下坏疽格改 78160 像素，与单张一致。

1. 颜色回到黄：厚苔用灰黄、乳黄、少量淡黄绿（PUS_TONES，不平涂），去掉 r5 近白径向雾。管窗（x 420–1700，y 280–540）内化脓态黄苔占脓+红像素的 46.86%（76058 / 162296），落在 40–60%。黄苔平均 RGB (199, 168, 107)。全景下化脓态读成黄。
2. 厚度和边界：厚处是同一粒种子的多层同心不规则填色，顶部略混亮乳黄、边缘略混暗赭，不透红；薄纱 alpha 低，透出下方红色。边缘仍不规则、羽化。无描边、无高斯模糊、无径向渐变雾。
3. 纤维素：只在厚苔（短径 ≥ 8、有效 alpha ≥ 0.45）上画 3 条顺长轴起伏细丝和 1 条较弱斜向交联。200% 能看出丝，不是模糊斑，也不是等距排线。密度是示意，不是计量。
4. 浆膜充血：血管仍由未改的 drawSurface 先画。脓苔没有铺满，间隙留红。化脓态下缘带（x 700–1500，y 470–530）相对 r5：33316 像素未变，14684 像素因厚苔铺到下缘而变。未覆盖处的小血管和暗红斑仍是 r5。
5. 坏疽态：paintNecro、凹陷和坏死破损未改。斑块内先铺 r5 的 paintPusLegacy，新黄苔裁在斑块外，交界处再叠污秽灰绿（PUS_DIRTY [114, 120, 86] 混入黄，这是选定的橄榄调，不是标本测色）。紫黑斑、中央凹陷和斑点仍是 r5 的画法。坏死区不是逐像素等于 r5：采样盒 (1340, 350)–(1560, 470) 改变比例 0.5508，通道绝对差均值 50.44。坏死层半透明，周围从发白雾换成灰绿后，晕边的合成色跟着变。交界仍略有分叶，不是一层完全连续的薄洗。
6. 200%：细节对比_r6.png（2880×940）是化脓、坏疽两行，r4 / r5 / r6 三列；源窗口与 r5 的细节对比相同，最近邻放大 2 倍。r6 无贴图重复、无硬描边、无发白雾。细丝是按苔块现画的短笔触，不是一张重复贴图。
