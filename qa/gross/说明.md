静态样张，无动画。场景 `?scene=gross_test`，时长 5 秒：t=0 正常、t=1 红、t=2 黄、t=3 黑、t=4 场景内 2×2。交付图由 `--still 0,1,2,3` 复制为中文文件名；`gross_四态.png` 是四张单图的 2×2 拼贴（各带标题与引线）。

```bash

node /workspace/garden-skills/skills/motion-showreel/scripts/render.mjs film --q scene=gross_test --determinism
```

未改 `engine/lib`。新代码在 `film/lib_ext/gross_appendix.js`、`film/chapters/gross_test.js`，`film/main.js` 只增加场景分发。未碰 v5 主工作区、v4_mix、配音环境。

## 用到的函数

- `figure.js`：`spine`、`halfW`、`specimenOutline`（管壁轮廓；尖端收束沿用引擎公式）
- `wash.js`：`bake`（`hd:true, soft:true, grain:.12, bleed:.5`；脓苔 `keepWhite`）、`get`。每张烘焙立刻 `getImageData` 拷到 CPU 画布再画（`drawPinned`），组织 `multiply`，脓苔 `source-over` + 一层 `multiply` 渍。软件 GL 会丢掉未读过的 2048 画布，所以不能等全部烘完再读。
- `ink.js`：`shape(..., dynamic=true)` + `draw` 双线管壁（2.6 / 1.2 屏幕像素，roughness .9 / 1.2，`boil:false`）、系膜游离缘、动脉/静脉/弓形吻合、浆膜面血管、浆膜高光短弧。动态生成是因为 2×2 与单图 `pose.sc` 不同，缓存 key 不含线宽，后画的会污染先画的。
- `ann.js`：`label`（字重 500 / 700 / 800）、`leader`（`elbow:true`，halo）
- `motion.js`：`rng(固定种子)` 生成浆膜血管，禁止 `Math.random`

肿胀量：正常 0.22、红 0.48、黄 1.0、黑 0.96（相对 `halfW` 的 swell）。构图：标本放在右主画面 x=570–1860、y=50–780，姿态约 `(1210, 400, rot=-0.16, sc=1.48)`。

## 还不够好的地方

1. **系膜**仍偏薄、偏空。游离缘有波浪，基部有切断宽度，但脂肪水彩不够厚，读起来仍像血管示意图而不是一块油膜。v4 的盲肠/系膜曾因「平楔形」被拒，这一版避开了尖楔，体积还不够。
2. **脓苔**斑驳、未整根涂黄，但 `keepWhite` 烘焙留下浅色笔触条纹（化脓性图中云团里的白划），灰黄 `#CDB98A` 有时偏粉白。规范里的 despeckle / dryRim 当前 `wash.js` 没有暴露。
3. **坏疽**是远端局部暗红–黑褐，没有整根涂黑，近端仍红；黑度更接近陈旧出血而不是炭黑。出血斑和充血底混在一起，引线「出血斑」不够指到独立斑块。
4. **正常浆膜光泽**只有三条白弧，整体仍偏平。圆柱体感主要靠腹侧略深的水彩，不够。
5. **尖端**沿 `specimenOutline` 在 s>0.9 收成尖点，盲端圆钝感不足。引擎函数的 `tip` 数组是空的，这一轮没有另造几何。
6. **表面血管**比第一版少平行排线，仍偏稀、偏直，扩张感不如实物浆膜充血。
7. 场景内 t=4 的 2×2 把每格画到纸色小画布再贴回（透明底上 `multiply` 会变黑）。交付的 `gross_四态.png` 是四张带标注单图的拼贴，便于对照引线。
8. `--determinism` 六个时点跨页乱序已通过（见 `determinism.log`）。渲染日志里的 404 是 favicon，不影响出图。
