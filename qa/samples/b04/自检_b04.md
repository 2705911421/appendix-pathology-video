# b04 CPU 自检

标准：逐张打开 Gisele指定_右侧为目标.png（只取右列）、t_089.73.png、t_099.22.png、sample_zoom.png 后实施。参考目录与 v4_mix 均未修改；assembly/ 未操作；未提交 git。

- **源码一致性**：lib/he_target.js、he_target_detail.js、wash_target.js 从指定 src 复制。修改相对 import 路径；wash_target 初始化复用主程序已建好的 brush 画布，避免第二个 p5 实例抢占全局 brush；水彩处理算法不变。check_b04.mjs 对三个文件做路径和初始化适配归一化后的全文相等断言。坏疽烘焙配方由 src/04.js 的 bake 原文提取到 he_target_bake.js。
- **中性粒细胞**：各倍率均调用目标 detailedNeutrophil，不再以深色实心点替代。2–5 叶轮廓、叶间距、细丝、胞质 rgba(226,170,200,.75)、颗粒 rgba(167,105,159,.38)、核 #51336F/#3F2A66 和随机种子均沿用目标。未引入粗黑指针。
- **红细胞**：坏疽出血盘和喷溅使用目标 disc / pushDisc / drawBlood，保留低饱和 #A8404E、边缘 #7E2A38、中央淡区、压扁旋转和溶血低透明。目标源码实际 rx=5*(.72+随机*.6)，即约 -28% 至 +32%，本次按“相同算法参数”保留，没有声称它是严格 ±20%。单纯期血管内保留约 rx=5，白细胞尺度约其 1.5 倍。
- **组织与水彩**：肌纤维、胶原及纤维素细网直接使用目标 tissueTexture / fibrinMesh。烘焙 hd:true、soft:true、grain:.12、edge:.3、bleed:.5。坏疽底色额外复用目标 c04.thromb 色素作三处大范围 multiply 铺染；此为适配切片的新增铺染位置，不是目标原函数参数的一部分。
- **坏疽**：prepareGangrene / gangrene 原文保留影细胞、碎核、出血、分层血栓、毛边裂隙、纤维残端和浆膜端脓。穿孔与脓按原第57句出现，s14_mid（54句）尚无穿孔，另存 s14_perforation（57句），避免提前显示病变。
- **分期密度**：单纯期以黏膜及黏膜下层细胞为主，肌层仍只有原5个零星中性粒细胞。化脓期中高倍用目标 CELLS 的全层1150个浸润细胞及腔内成团脓细胞；坏疽按目标 coreAt 等算法消退核结构并叠加碎核/影细胞。
- **黏膜**：隐窝长短、宽度、倾斜均有固定种子变化，轮廓另加弯曲和粗细变化；柱状上皮夹淡染杯状细胞。固有层增加小圆深核淋巴细胞和偏位车辐核、核旁淡区浆细胞。滤泡保留深染套区与淡染生发中心。
- **低倍**：组织坐标长轴乘1.6，另有多频波形扰动；目镜仍为圆。低倍镜头 zoom=.52、x=340、y=-280，切片显著大于目镜并偏置裁切；管腔随组织成为不规则椭圆。红框随后按既有 camera 插值推入中高倍。
- **b03 保留**：黏膜肌层细带、浆膜间皮、内环肌梭形核、外纵肌圆点核、目镜外便签；目标全层场上补画黏膜肌层、外纵肌与间皮标志。高倍路线仍为30血管游出→31黏膜→32肌层→33回推→34缺损。镜下 leader 沿用1.6px。
- **输出与对比**：render.mjs --samples 写入 b04 的指定样帧，并额外输出33句与57句。对比图左目标右v5，上行化脓、下行坏疽穿孔（右侧使用额外的57句穿孔样帧）；裁取目镜组织区域。v5采用由浆膜向黏膜的画面方向，与目标的上下方向相反，但解剖层次相同。

验证：node tools/check_b04.mjs 检查源码、2000个相机连续采样点、9帧正反顺序哈希及内容边界。CPU 使用 Canvas2D brush 预览适配器；其水彩质感不能视为 Chromium/p5.brush 最终验收。最终 Chromium 出图和对目标的视觉签收由 mini 完成，不能将 CPU PASS 写成最终画风完全一致。
