# S13 mech 自检（终局黑，句 49–53）

## 逐句画面

时间全部走 `forScene(49, 53)` 和 `T.frac` / `T.at` / `T.end`，没有把旁白秒数写进节拍。左栏只使用定稿和分镜里已有的话，没有数字、研究或文献。

- 句 49「终局黑：腔内压力升高，危机步步逼近。」左栏标题「终局黑」，要点「腔内压力升高」。右侧阑尾横断面：黏膜、黏膜下层、肌层、浆膜，腔内短箭头向外，没有刻度。肌层里的小血管随压力变扁。引线「腔内压力」落在腔内。
- 句 50「血管受压或形成血栓，阑尾壁陷入缺血。」左栏「受压／血栓 → 缺血」。圆窗里上下两条壁内血管，是这一句的两条路，不是声称两者必定同时发生。上支管壁收窄，外有指向管壁的箭头，无刻度；血流符号在狭窄前停下，狭窄远端红细胞变少变淡，标「缺血」。下支为闭塞性血栓，血流符号停在栓前，栓内有纤维丝和卡住的红细胞，标「血栓」。
- 句 51「血流受阻，组织坏死，还伴有出血。」圆窗换成阑尾壁：一条被血栓堵住的壁内血管，旁边是平滑肌束。靠近血管的肌束核消失、只剩核尘，色调发灰，标「坏死」；远处仍留梭形核，用来看出是局部坏死。红细胞漏到肌束之间，标「出血」。
- 句 52「坏死与血红蛋白分解产物，」同一视野里，出血处出现褐黑斑和色素颗粒，标「血红蛋白分解产物」。没有写分解产物的名字、浓度或时长。
- 句 53「让局部暗红，甚至发黑。」切到大体特写。用的是 v5_gross_dev 第四轮坏疽态的副本（`film/lib_ext/mech_gross_appendix.js`），stage 从 2.52 收到 3。黑斑标「发黑」，远端仍为暗红的浆膜标「暗红」。没有画穿孔（`pit: false`），因为这五句没有讲穿孔。

血管和红细胞对齐 S06 正在用的画法：双凹圆盘、中央淡区、水彩颗粒；管腔内有流向的尖括号；内皮上有少量贴壁的分叶核白细胞。白细胞没有单独加标签，不把它讲成坏疽的原因。

## 拿不准、也没有猜着画的地方

- 横断面是教学示意图，各层厚度和血管数量不成比例，不是一张真实切片。
- 句 50 把「受压」和「血栓」画在同一窗的上下两条血管上，只为同时看见两条路。
- 句 51–52 的肌束是壁的示意，不是按 HE 全层计数画的镜下视野。核消失表示局部坏死，没有画成全部结构消失。
- 血红蛋白分解只画成出血处的褐黑斑，不命名含铁血黄素或胆红素，也不给时间。
- 大体沿用第四轮坏疽资产，画法未定稿，以后整库替换。资产里原有的灰黄苔没有加标签。这一镜是坏疽态局部特写，没有画正常阑尾；库内正常态半径仍是细长的（`NORMAL_RADIUS = 35`，stage 0 的 `SWELL_K = 1`）。
- 贴壁白细胞是和 S06 血管画法对齐的形态，画面上不命名。
