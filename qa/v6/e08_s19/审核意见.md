# e08 修改前独立审核

对照 e07 三行对比右列、sample_zoom.png 和指定右侧目标，按相同原始像素裁切后 200% 查看。

1. 间质：e07 连续浅粉底占比高，细丝多是短小粉色碎片；目标有横向长细丝、玫红深浅团块及少量淡裂隙。主要差距成立。
2. 接缝：纤维化中部可见矩形纹理边界，需同时检查母板分块、高精度贴片与纤维化细胞分布的矩形裁切，不能只增加噪声遮掩。
3. 梭形核：已有长核，但仍有短钝椭圆；需要尖端、适度弯曲及与同倍率淋巴核的比例统一。
4. 浆细胞：偏心核及核旁淡染区可辨；背景细丝不足，邻近细胞在放大后显得稀疏。增加同一母板内邻近淋巴细胞，保留中心浆细胞。

样张用于色彩、纹理和比例参考，其中团簇的分叶形态不作为慢性炎细胞模板。不得把慢性浸润改成中性粒细胞。
