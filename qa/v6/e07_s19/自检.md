# S19 e07 细节与质感自检

本场景（句 69–70）由 Codex 起稿、WorkBuddy 接续修改、Codex 在再次中断后统一交付。基线为 s19-dev HEAD 515ca2d（tag v6-s19-e06）；开工已读 e06 自检、对比图及 e01/e03/e05/e06 的硬约束。产品改动仅 film/chapters/s19.js、film/lib_ext/he_chronic.js。

接续时先按样张复核首稿，发现两处回退并重做：梭形核内部加了浅色斑点，被画成"亮心中针"；间质改用大量小多边形填充，出现硬边"碎瓷片"观感。本轮把梭形核改成单一深紫填充、无光心，间质改回径向渐变的软边水彩团块。小核首稿偏灰、相邻核粘连使计数掉到 318，加深底色并把核径收窄后回到 370。为让计数与形态同时成立，梭形核本地场的数量由 600/200 下调到 420/150（视觉上首稿的梭形核也比样张密）。

## 逐条修改

1. **梭形核**：本地梭形场改用"宽度按 sin^0.5 变化 + 轻微弯曲 + 边缘扰动"的闭合轮廓，两端收尖但保留一点身宽，长径 25.2 px、横径 5.29 px，与样张 25.6/5.31 基本重合。内部不再叠浅色斑点（首稿正是它把核画成两根平行针），只留低透明度深紫斑。大尺度梭形核在浆细胞焦点附近按半径排除，避免推近后横贯画面。
2. **小核质感**：核底色由 e06 的 #55356F 调到 #4F2E67，外圈深染色质团块的遮盖率下调（.82→.78 透明度但半径更小），内部浅染颗粒改为 #7E6096、透明度 .5，使核保持深紫而内部可见深浅颗粒。轮廓段数由12提到24、振幅由.13降到.085，去掉首稿的"多面体"切割感，保留轻微不规则。淡色胞质/核周晕沿用 e06 的窄边。全部在 prepare 母图或高分辨率局部图中预烘焙，逐帧只采样画布。
3. **浆细胞那一拍**：末段镜头由 28 改为 22（WorkBuddy 续跑末段调整为22，本轮核对代码及最终帧），与前面 4.8× 的淋巴拍连续，像换高倍镜而不是整片放大。周围小核随同一张母图缩放，因而与母图尺度一致；浆细胞核仍用 24× 分辨率的局部图，染色质细节不糊。原先横贯画面底部的长梭形轮廓已消失（本轮局部图复核，见 s70_plasma_200pct.png）。
4. **间质**：首稿的 12000 个小多边形团块已删除，换成 1500 个椭圆径向渐变（深粉/浅粉两种，0→55%→100% 三段透明度）叠加，边缘无硬线，形成块状深浅起伏；每个团块内再撒 7 个颜料颗粒。细纤维的旋转扰动由线性 ±1.25 rad 改成三次方加权（多数贴近胶原走向、少数明显偏转），保留黏膜下/肌束间的成束胶原，同时打破首稿的交叉网纹。另加 900 条极淡长刷痕（alpha .05–.10）。
5. **团的排列**：紧密实心团的候选位置加入独立随机扰动（角度 ±0.45 rad、半径 ×0.84–1.16），减少同向螺旋重复；纤维化区边界由硬删除改为按距离概率保留，边界过渡更柔和。

S08七帧、S10八帧MAE=0。S11八帧与e02历史值逐项一致，三帧既有非零仅记录，未改基线。以上 parity 帧本轮全部用最终代码重渲。determinism_final.txt为最终22×版本独立页面、不同顺序渲染检查，六帧一致。七项锁定文件开工/收工SHA256一致且与e02基准一致。git diff --check通过。

## 仍不足

间质仍缺样张那种致密的平行细纤维纹（本轮只有很淡的长刷痕），团块分布也比样张均匀，样张下部有一片更深的嗜酸性积染区，我们没有。小核只有约五个原生像素，200%下能看到边缘与深浅差异，但达不到样张的亚核细节；核轮廓虽然不再是多边形，仍比真实淋巴细胞规整。梭形核的排列仍带轻微"梳齿"感（同一走向成排），真实组织里更随机。团簇仍是程序化候选位置加近邻拒绝，未模拟力学挤压。高倍浆细胞镜头是 22×，与淋巴拍 4.8× 不同屏幕倍率，只能作质感对照。中倍细胞沿用 e06 的区域尺度校准，不代表整片统一微米比例尺。母图准备耗时随软件渲染负载波动（既有日志约90秒至18分钟），首次渲染需等待（渲染器会打印 READY 等待提示，属正常）。

环境备注：本机 Chrome 走 ANGLE/Mesa llvmpipe，要求 DISPLAY 指向运行中的 Xvfb（本机为 :1）；DISPLAY 指向已停止的 X 服务时 WebGL 会直接创建失败。页面日志里的 404 是浏览器自动请求 /favicon.ico，不影响渲染。
