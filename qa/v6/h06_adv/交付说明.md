# main_adv01（Codex）

- 审核意见.md：独立审核与修正依据。
- s06/、s07/：逐句 PNG、200% 局部、修正前后对比、review_sheet、无字幕场景 MP4、带真实配音及原字幕的 720p MP4。
- review_sheet.png：两场景总览。
- 粗剪_v15.mp4、粗剪_v15_720p.mp4：以 v14 为底，仅替换 S06/S07 精确窗口，音轨整轨复制。
- verification.json：窗口外视频包、音频包及时间戳、安全区、换序复绘与圆外接缝核对。
- subtitle_verification.json：原字幕区域逐帧编码色差。
- boundary_review.png：连续解码所得接点总览。
- audio_verification.json：逐场景真实配音与全稿 v3 旁白波形相关性。
- locked_start.sha256、locked_end.sha256：锁定文件开工/收工校验。
- main_adv01-dev.bundle：原 Git 元数据只读时的提交交付；详见 commit.log。

重建顺序：node qa/v6/h06_adv/render.mjs；python3 qa/v6/h06_adv/reviews.py；python3 qa/v6/h06_adv/build_v15.py；python3 qa/v6/h06_adv/verify.py；python3 qa/v6/h06_adv/audio_verify.py。渲染共用一个浏览器，场景顺序执行；ffmpeg 单线程。

换序检测遵循 render.mjs 的现有容差：单通道差大于 24 的像素占比不超过 0.0005；同时保留像素差实测值，未把容差通过表述成逐字节零差。
