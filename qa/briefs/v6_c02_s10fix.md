# v6 c02（Codex）：S10 修三处

工作目录 /workspace/病理科普视频/v5，分支 v6-fresh，基于 HEAD（a2e9ba5，即 c01）。不许 git commit。硬约束、画风标准和镜头规则与 qa/briefs/v6_c01_s10.md 完全相同，开工前先读一遍。S08 parity MAE 必须为 0，determinism 必须通过，sha256 开工和结束各校验一次。

这一轮只改 S10 的三处，其余句子的画面不应有明显变化。

1. **句 40（脓液成分）**
   - 视野中间那块边缘生硬的白色椭圆空洞要去掉，或者改成淡染、边界柔和、明显是"渗出液"的区域。不允许出现纯白的硬边形状。
   - 组织碎屑要让人看得出来：加淡伊红色、无结构的颗粒、絮片、残破的胞质碎块，以及少量核碎片小点，大小不一、分布不均，混在脓细胞之间。
   - 渗出液用淡粉色水彩薄层，要比周围组织略亮、略透，能和碎屑分得开。
   - 脓细胞、碎屑、渗出液这三种成分，在 200% 局部里都要一眼就能认出。
2. **句 42（脓细胞特写）**
   - 改成清楚的对照构图：画面中心偏左放 1 个典型的分叶核中性粒细胞（3 叶，胞质淡粉，边界清楚）；右侧紧挨着放 3 个脓细胞，分别是核固缩成深色圆团、核碎裂成多个小点、胞质模糊溶解边界不清这三种。
   - 背景减淡（可以是疏松水肿的间质或脓液背景），别让粗大的肌束纹理抢了视线。
   - 两个标签"中性粒细胞""脓细胞"分开放：前者在左上，后者在右下，引线短，各自指向对应的细胞（"脓细胞"可以用一条分叉引线同时指向 3 个），文字之间不重叠，也不压在细胞上。
   - 左栏的引线不要穿过视野中心。
3. **低倍（句 37 开头）**
   - 四层分界要更清楚：黏膜（隐窝 + 固有层）、黏膜下层（疏松、水肿、淡）、肌层（粉色肌束，可见中性粒细胞穿插）、浆膜（外缘，有一薄层纤维脓性渗出），层与层之间看得出边界。
   - 黏膜上要有 2–3 处明显的溃疡缺口，在低倍下就能看出来；可以复用 S08 断线的做法，即从源头不画那段上皮线。
   - 打破隐窝和血管的重复节律：隐窝的大小、间距、斜切角度要随机化，部分隐窝要被炎细胞破坏，变得不完整。
   - 低倍时画面依然通透，平均亮度不要明显低于 S08 的低倍。
4. 视频编码：粗剪不需要无损。最终的粗剪 v4 用 libx264 -crf 16 正常编码即可。另外不再要求纸色段逐帧哈希一致，只需抽 3 帧纸色帧验证 MAE<1.0。
