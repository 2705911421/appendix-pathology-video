# v6 g02（Grok Build）：在 b05 底子上加腺体，保持通透

Gisele 看过 b05 和 g01 的对比后，定的方向是：用 b05 做底子，加入不规则、斜切的腺体，保持通透。
film/ 已经撤回到 b05（标签 v6-b05-keep）。你在 g01 里写的 s08.js 和 cells_ext.js 存在 qa/v6/g01_ref/ 里，可以从中挑可用的部分（比如 cryptNucleus 和 columnar），但不要整段照搬。
锁定文件、出图程序、determinism 检查、不许 commit 这几条规则都和 g01 一样（见 qa/briefs/v6_g01_mucosa.md）。

## 低倍（t=1）
- 保留 b05 的整体观感：底色浅、通透，能看出 b05 现有的细胞点和层次。不要像 g01 那样把整个黏膜铺成一块浓重的紫色色带。
- 在 b05 的黏膜带里，把放射状的辐条状隐窝换成真实的腺体：管状腺的长短、粗细、间距都不均匀，略带弯曲；其中约三分之一是斜切的（短椭圆小环）或横切的（小圆环）。腺上皮是一圈细小的深紫色基底核，腺腔淡染、通透，不加描边线。
- 腺体之间是固有层，里面散在淋巴细胞和浆细胞，密度大约和 b05 相当，不要更浓。
- 黏膜带和黏膜下层的分界要柔和。黏膜肌层是一条细的粉色线，不要画成硬边。
- 判断标准：黏膜的平均亮度大致在 b05 和 g01 之间，更接近 b05。用 Python 量一下黏膜带的平均 L 值，b05、g01、g02 三个版本都量，写进报告。

## s34（t=33）上皮局灶缺损
- 缺损要一眼看得出来：表面上皮带中间断开一段，宽度约占视野的 15–20%，两侧的残端参差不齐，是撕裂状的，不能是整齐的切口。
- 缺损面上覆盖一薄层淡粉色的纤维素丝网，中间夹着若干个 detailedNeutrophil；这些渗出物略微高出原来上皮表面的位置。
- 缺损下方的固有层充血，可以加少量红细胞，红细胞照 he_detail.js 的写法来画；水彩晕染的参数照 04.js（hd:true, soft:true, grain:.12, edge:.3, bleed:.5）。
- 讲解卡片的指引线要指向缺损。
