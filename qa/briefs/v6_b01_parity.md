## 铁律
1. engine/lib/he.js、he_detail.js、wash.js、ann.js、scope.js 一个字节都不许改。先记下 sha256，结束时再校验并写进自检。新场景只能 import 并调用它们的函数，参数照抄 04.js（hd:true, soft:true, grain:.12, edge:.3, bleed:.5 等）。需要新形状（斜切椭圆）时，在 scenes/ 下新写调用层，不准重写细胞、红细胞、纹理和水彩的绘制。
2. 第一步：在 v6 里用 engine 原样重现 t_089.73 与 t_099.22 两帧，像素和参考图逐帧对比，输出 qa/v6/parity/ 下的对比图与差异数值。差异明显就停下，并写明原因，不要继续往下做。
3. 第二步（只在第一步通过后做）：按 分镜/分镜_v1.md 与 qa/病理验收清单.md 做 S08 显微镜段。
   - 低倍：斜切、略不规则的椭圆横断面（长短轴比 1.4–1.8），比视野大，被目镜裁边，管腔不规则，不画完整正圆环。
   - 低倍到中倍到高倍连续推镜，倍数标签只写"低倍/中倍/高倍"，不写数字。
   - 高倍路线按句号 id 计时：30 扩张的黏膜下血管和中性粒细胞游出；31 上到固有层和黏膜；32 往下扫过黏膜下层到肌层，肌层里只有少量；33 往回走，经过受损的细胞；34 停在上皮局灶缺损处。只移动到相邻层次，不跳切，不加装饰性漂移。
   - 肌层：内环行肌是长梭形核，外纵行肌是圆点核。
   - 讲解卡片只在对应句出现，放在目镜外的暗区，用完就退场；指引线 1.6px 细线。内容一律在 y<950 以内，下方留给字幕（中文 52px，英文 30px）。
4. 你的沙箱启动不了 Chromium，可以用 CPU 后端自检，但要在自检里写明。最终出图由 mini 用 Chromium 执行，所以必须提供 `node render.mjs --samples` 命令，输出到 qa/v6/samples/。
5. 不许改 assembly/、v4_mix/，不许 git commit。
